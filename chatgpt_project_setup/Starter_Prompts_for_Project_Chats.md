# Starter Prompts For The ChatGPT Atlas Project

Use one chat per task or per chapter. Do not write the whole book in one chat.

## 1. Project Orientation Chat

```text
Using the uploaded Book Project Master Brief, chapter map, terminology register, fact ledger, current status, and manuscript drafts, create a concise project orientation for this VaR monograph. Identify: central thesis, current manuscript status, chapter-by-chapter production risks, missing verification tasks, and the next 10 actions for producing a coherent Word-first manuscript.
```

## 2. Master Brief Improvement Chat

```text
Review the uploaded Book Project Master Brief for this VaR monograph. Improve it as a living project brief. Keep the Word-first workflow, VN-Index empirical focus, Vietnamese academic style, and eight-chapter architecture. Ask only for missing information that materially affects book production.
```

## 3. Chapter Review Chat

Replace `Chapter X` with the actual chapter.

```text
Review Chapter X as part of the whole VaR monograph, not as an isolated draft. Assess chapter thesis, function in the book, overlap with adjacent chapters, missing citations, unverified empirical claims, terminology consistency, figure/table integration, and transition quality. Do not rewrite yet. Return a prioritized revision plan.
```

## 4. Chapter Outline Chat

```text
Using the Book Project Master Brief, chapter map, and current manuscript draft, create a revised detailed outline for Chapter X. For each section, state: section thesis, function, evidence or citation needs, expected figure/table if any, and transition to the next section.
```

## 5. Section Drafting Chat

```text
Draft Section X.Y in Vietnamese academic style. Follow the approved chapter outline and terminology register. Do not invent citations or empirical results. Mark unsupported claims as [citation needed] and unstable factual/current claims as [verification needed].
```

## 6. Literature Architecture Chat

```text
Create a literature architecture for Chapter X. Separate: seminal works, recent frontier literature from the last 3-5 years, review/survey papers, theory papers, method papers, policy/regulation documents, competing explanations, unresolved debates, and literature gaps that support the chapter thesis. Do not invent citations. If live search is needed, propose the search strategy first.
```

## 7. Current Literature Update Chat

```text
Use live search/deep research to update the literature for Chapter X. Prioritize peer-reviewed papers, top field journals, authoritative working papers, and official regulatory/method documents. Produce a literature matrix with citation, research question, data, method, findings, limitations, and how it supports or challenges the chapter thesis. Do not include unverifiable citations.
```

## 8. Empirical Verification Chat

```text
Using the uploaded data files, processed outputs, and available R outputs, create an empirical verification checklist for Chapter X. Identify which exact numbers, charts, captions, model rankings, data periods, and backtesting claims are verified, missing, or need rerunning. Do not create final prose until the verification status is clear.
```

## 9. Figure/Table Integration Chat

```text
For Chapter X, inspect the draft and available outputs. Build a figure/table integration plan: item title, file source, where it belongs in the chapter, what claim it supports, caption requirements, interpretation paragraph, and verification status.
```

## 10. Chapters 6-8 Word Conversion Chat

```text
Using the Quarto archive, chapter map, and current book brief, design a Word-first production plan for Chapters 6-8. Identify what can be migrated, what must be rewritten, which empirical outputs are required, and which claims need verification before prose.
```
