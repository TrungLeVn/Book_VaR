# Chapter 1 Code

This folder stores the active Chapter 1 R workflow.

## Run

From the repository root:

```bash
Rscript '01. Chuong_01/code/ch01_all_in_one_Rscript.R'
```

Or from this folder:

```bash
Rscript ch01_all_in_one_Rscript.R
```

## Inputs

- Local chapter copy: `01. Chuong_01/data/raw/vnindex.csv`
- Shared raw inputs assigned to Chapter 4: `04. Chuong_04/data/raw/`

## Outputs

Generated files are written to:

```text
01. Chuong_01/output/
```

Main subfolders:

- `figures/`
- `tables/`
- `estimates/`
- `docx/`
