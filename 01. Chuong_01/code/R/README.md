# Chapter 1 R Modules

This folder contains the modular Chapter 1 workflow:

1. `00_ch01_setup.R`
2. `01_ch01_appendix_tables_figures.R`
3. `99_ch01_export.R`

Run all modules with:

```r
source("01. Chuong_01/code/R/run_ch01_all.R", encoding = "UTF-8")
```

Outputs are written to `01. Chuong_01/output/`.
